============================================================
1. EXECUTIVE SUMMARY
============================================================

A series of failed network authentication attempts were
detected against the Windows Server 2025 virtual machine.

Five failed authentication attempts were generated against
the "soc-test" account from the Kali Linux virtual machine.

The attempts originated from source IP address
192.168.87.128 and targeted Windows Server 2025 at
192.168.87.129.

All five attempts generated Windows Security Event ID 4625
with Logon Type 3 (Network).

The attempts occurred within an 8-second period.

No corresponding successful Event ID 4624 authentication
was identified during the investigated timeframe.

The activity is therefore classified as an unsuccessful,
controlled brute-force authentication simulation.

============================================================
5. INVESTIGATION
============================================================

The investigation identified the following characteristics:

1. Five Event ID 4625 failures were observed.

2. All attempts originated from the same source IP:
   192.168.87.128.

3. All attempts targeted the same account:
   soc-test.

4. The authentication type was Logon Type 3,
   indicating network authentication.

5. The failure status was 0xC000006D.

6. The failure sub-status was 0xC000006A, indicating
   an incorrect password.

7. The five attempts occurred within an 8-second period.

8. Event ID 4624 was checked to determine whether the
   authentication attempts eventually resulted in a
   successful login.

9. No successful Event ID 4624 authentication was identified
   during the investigated timeframe.


============================================================
6. ATTACK PATTERN
============================================================

The observed behavior is consistent with a brute-force
authentication pattern because multiple authentication
attempts were made against the same account from the same
source within a short period.

The activity was intentionally generated as part of a
controlled cybersecurity laboratory.

The source IP address 192.168.87.128 belongs to the Kali
Linux attacker VM used in the laboratory.

10. IMPACT ASSESSMENT
============================================================

No evidence of successful account compromise was identified.

No successful authentication was observed following the
five failed attempts.

The activity therefore represents an attempted authentication
attack rather than a confirmed successful compromise.

============================================================
13. RECOMMENDED SOC RESPONSE
============================================================

If this activity occurred in a real production environment,
the SOC analyst could:

1. Validate whether the source IP is expected.

2. Determine whether the targeted account belongs to a
   legitimate user or service.

3. Check for successful Event ID 4624 activity.

4. Review additional authentication activity around the
   same timeframe.

5. Check whether other accounts were targeted.

6. Investigate account lockout or suspicious account activity.

7. If malicious activity is confirmed, apply appropriate
   containment according to organizational procedures.

8. Reset credentials if compromise is suspected.

9. Escalate the incident if successful authentication or
   additional suspicious activity is identified.


============================================================
14. FINAL CONCLUSION
============================================================

The investigation identified five failed network
authentication attempts against the "soc-test" account.

All attempts originated from 192.168.87.128 and targeted
192.168.87.129.

The attempts generated Event ID 4625 with Logon Type 3 and
occurred within an 8-second period.

The authentication failures contained Status 0xC000006D
and Sub Status 0xC000006A, indicating invalid credentials
and an incorrect password.

A search for Event ID 4624 found no successful authentication
during the investigated timeframe.

The activity is classified as a controlled and unsuccessful
brute-force authentication simulation.

No evidence of successful account compromise was identified.
